# LearnLoop - Autonomous Learning Planner

A simple web app to help students plan and track their studies.

Built by Sanjali as a college project.

### Features
- Add subjects with deadlines and difficulty
- Auto-generates daily study timetable
- Tracks hours studied and progress
- Study Coach chat to clear doubts
- Help them to know how to start a subject in which they are'nt confident

### Tech Used
- React + TypeScript
- Node.js
- Gemini API for AI coach

### How to run on your system
1. npm install
2. Create .env.local file and add your Gemini API key
3. npm run dev
